# LOOPER｜視覺成果優先驗收契約 V1

本區是內部製作驗收，不建立第二種玩家介面版。正式產品依 ADR-002 維持單一沉浸式 App。

## 每項製作強制具備的可見成果

1. 先交可直接觀看的原圖／動畫 GIF 或影片，不先交難以閱讀的程式報告。
2. 再交實際放進 Forest / Treehouse 的場景合成、原件版本、來源 ID 與 SHA。
3. 圖像需有 9:16 和 9:19.5 兩種裝置畫面；新增互動需要真實可點入口及錄影。
4. 產物標記四個獨立欄位：美術審美／可編輯母件／工程互動／真機 QA。不可把任何一項工程測試通過當成新宇宙美術核准。
5. 正式美術進度仍寫回既有 [Visual Asset Register](https://docs.google.com/spreadsheets/d/1pU4kQN8ZyvgXHKzJRWCdNbmDaZsgl7ZisR6ZwvYcd1M/edit)，禁止另建一套互相矛盾的主表。

## 兩種能直接觀看的驗收入口

- **GitHub Actions｜Looper Visual-First Art Showroom**：下載名為 Looper-Visual-Art-Showroom 的 Artifact ZIP，解壓縮後雙擊 index.html。它直接以現有 PNG 生成縮圖、分類、搜尋、原圖放大以及缺件卡片，不產生任何假圖。
- **Expo 開發模式**：歡迎頁出現「🖼️ 製作驗收台（開發限定）」；可看已匯入場景、道具和任務圖像的 8 種狀態，切換 9:16 與 9:19.5 背景比例，並點擊打開真實 Forest 互動。正式 Release 不顯示入口。
- 既有 W2-03 Web 視覺測試保留 9:16／9:19.5 螢幕截圖供對照，**不能替代 iPhone 實機驗收**。

## 每種作品必有的展示

| 類別 | 看到的成果 |
|---|---|
| 場景 | 原生分層、同一構圖背景、手機截圖、合法光線變體 |
| 角色 | Canon 同源原件、原地循環動作 GIF／影片、接地影與森林融合 |
| 物件 | 真透明素材、放大細節、場景中的位置及比例、獨立可編輯母件 |
| UI | 展開、收合、答題、返回等連續操作錄影及手機實機截圖 |
| 系統資料 | 真正的動態文字、進度、店家資料；不能把帳本資訊烘焙進美術圖 |

缺圖時直接標為缺件；有圖但沒有可編輯母件不得標素材完成，有程式但沒有遊玩畫面不得標 App 完成。
